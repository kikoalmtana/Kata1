### Objetivo de la entrega

### Como compilar y ejecutar, dependencias y versión de JDK

Para compilar y ejecutar el proyecto basta con descargar el proyecto y ejecutar la main()
de la clase Main en el directorio del proyecto src/software/ulpgc

Se ha elaborado esta práctica con Java 22 y JDK 23

### Estructura de la entrega, clases principales y flujo git

El desarrollo de la Kata se ha centrado en el directorio src/software/ulpgc cuyas clases principales son:

- Clase Main: Clase principal donde se ejecuta el código
- Clase Person: Clase implementada con 2 atributos privados, cuyos métodos se han generado automáticamente usando las utilidades de IntelliJ y que implementa métodos que devuelven atributos derivados

En este repositorio se encuentran 5 ramas donde se ha repetido la Kata deliberadamente (ramas primera/segunda
/tercera/cuarda/quinta-repeticion) repitiendo los mismos comandos, atajos de teclado y shortcuts que
se utilizan en el video hasta ganar cierta soltura, y una rama master donde se realizó el video explicativo
